## 继承的构造函数
当子类和父类都没有构造函数时，会调用默认无参构造函数。
当子类需要调用父类的有参构造函数时，需要在派生类的构造函数的参数列表中，显示调用。
简而言之，基类中的构造函数，靠派生类中的构造函数进行初始化。

## 特殊类成员的初始化
对于类中的内部类对象，它的初始化顺序是 1.基类构造函数 -> 2.内部类对象构造函数 -> 3. 派生类构造函数体

## 继承的析构函数
析构哈数的执行顺序为：1.派生类析构函数-> 2.内部类对象的析构函数 -> 3. 基类的析构函数
这与构造函数的顺序是相反的。

## 多基继承

### 多基继承的权限
针对多基继承，每一个类都需要有权限标识符，因为默认继承权限是private
```c++
// 只有 A 是public 继承，B, C都是private继承，A 类对象无法访问成员。
class D: public A, B, C {}; 

// 正确
class D
: public A
, public B
, public B 
{};
```

### 多基继承的构造函数调用
顺序只跟继承顺序有关，跟派生类的初始化列表无关。

### 多个基类中相同的成员函数访问
```c++
// ERROR
D d;
d.print();
d.print();
d.print();


// 正确
D d;
d.A::print();
d.B::print();
d.C::print();

```

### 存储二异性
当 D 继承了 B 和 C，B 和 C 继承了 A，D 的对象使用了 A 中的方法时，B 和 C 中存储的两个 A 的方法会产生二义性。
怎么解决呢？那就是采用`virtual`关键字进行虚拟继承。

### 虚基指针
A 类中有一个double 数据成员 \_idx，所以 D 继承了 B 和 C 后，B 和 C 的大小为 8 字节，因为各自有一个\_idx, D 的大小为 16，因为里面有两个\_idx。
当虚拟继承 A 后，B 和 C 成了 16 字节，因为多加了 `1` 个`虚基指针`，D 的大小变为了 24 个字节，因为有两个虚基指针，和一个 double 数据成员。
这个过程中，成员方法是不占类的大小的。
