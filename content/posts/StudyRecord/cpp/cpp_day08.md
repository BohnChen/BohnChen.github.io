## 运算符重载
由于要对自己定义的对象进行操作，所以要有运算符重载。
运算符重载不能改变符号原本的定义，操作数中至少需要一个自定义类型或者枚举类型

运算符重载之普通函数，访问私有成员，需要用类内get函数
运算符重载之成员函数，由于非静态成员函数的第一个位置是this指针，需要注意参数个数，比如+运算符只有两个参数
运算符重载之友元函数，可以直接访问私有成员了。

普通的运算符重载，比如 + 运算符，两个值返回一个新的值，推荐以友元函数进行运算符重载。

特殊的运算符重载，比如符合运算符 \*=,+=,/= 等运算符由于需要改第一个操作数，所以建立用成员函数的方式进行重载。

自增运算符重载
由于
```c++
int a = 3;
++a; // 表达式为 4， a = 4
a++; // 表达式为 4, a = 5
```
所以我们要考虑两个不同的 ++ 运算符重载

```c++
MyClass &operator++() {
  cout << "MycClass operator++ " << endl;
  _x++;
  _y++;

  return *this;
}

// 用一个无用的int来做前置++和后置++的区分
MyClass operator++(int) {
  cout << "MycClass operator++(int) " << endl;
  MyClass tmp(*this);
  _x++;
  _y++;
  // 调用拷贝构造函数
  return tmp;
}

```

输出流运算符的重载
不能放到类中去，因为对于输出流运算符，第一个操作数是ostream，如果放到类内，就改变了操作数顺序，这是不可以的。
放到全局中时，作为普通函数进行输出流运算符重载，发现数据成员是私有的，因此我们最好将其声明为友元

### 友元
应该尽量合理使用。

友元不受 private,protect控制，
友元之普通函数
友元之成员函数
友元之友元类

友元函数需要单独设计为友元，不会因为函数名相同，就设计了一批友元函数。

单向：而且友元是单向的，在 A 类中设计了别的友元后，别的友元可以访问 A 中的私有成员，但是 A 中的函数无法访问这个友元中的值。
无传递性：A -> B -> C,但是 C 不一定是 A 的友元
无继承：友元不能被继承
