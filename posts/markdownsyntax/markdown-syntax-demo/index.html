总结
#

以上基本涵盖了本站可用的 Markdown 语法。核心要点：

  1. 下划线、颜色用 HTML 标签（<u>、<mark>、<span>）
  2. 提示框、徽章、按钮等用 Blowfish shortcode
  3. 数学公式、流程图分别用 math 和 mermaid shortcode
